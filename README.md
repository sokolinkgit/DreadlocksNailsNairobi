# Sisterlocks Nails Art Salon

Single-page marketing site for **Sisterlocks Nails Art Salon** (Nairobi) — dreadlocks/loc
services and luxury nail artistry, booked by phone or WhatsApp.

All services are delivered **in-studio at the central Nairobi salon** — house calls and
mobile visits are no longer offered.

## Files

- `index.html` — the full landing page (hero, before/after gallery, price calculator,
  service menu, combo deals, reviews, FAQ, booking form)
- `style.css` — styles
- `script.js` — interactivity (sliders, calculator, WhatsApp link builder, FAQ, toasts)
